# File upload limits

File upload limits are based on the **form owner's plan**, not the respondent's.

**Maximum size per file**
- Free: 10 MB
- Starter: 25 MB
- Pro: 100 MB
- Business: 250 MB

**Total storage per account**
- Free: 100 MB
- Starter: 2 GB
- Pro: 20 GB
- Business: 100 GB

When storage is full, new uploads are rejected until you delete files or upgrade. Other fields keep working.

**Other limits**
- Up to **10 files** per file upload field per response.
- Uploads time out after **10 minutes**, so large files on slow connections can fail.
- These file types are always blocked for security: .exe, .bat, .cmd, .sh, .msi, .js, .vbs and .scr. Blocked types cannot be allowed on request; ask respondents to send such files inside a .zip archive.
- Every file is scanned for malware; infected files are rejected.
- You can restrict each upload field to specific file types in its field settings.

**If respondents report upload errors**
Check the file size against your plan, the file type, the field's allowed types and your remaining storage. Ask the respondent to retry on a stable connection. Failed uploads do not count against storage.
