# Webhooks

Available on **Pro and Business**. Webhooks send each new response to your own server as an HTTPS POST with a JSON body.

**Setup**
Go to Form > Integrations > Webhooks and add an endpoint URL. Only HTTPS URLs are accepted. Each form can have up to **10 endpoints**.

**Delivery and retries**
- Your endpoint must return a **2xx status within 10 seconds**. Anything else counts as a failure.
- Failed deliveries are retried **5 times with exponential backoff**: 1, 4, 16, 64 and 256 minutes after the previous attempt (about 5 hours 40 minutes in total).
- If all 5 retries fail, the delivery is marked **Failed**. Failed deliveries stay in the delivery log for **30 days** and can be resent manually with **Resend**.
- The response itself is always saved in Larkspur, whether or not the webhook succeeds.
- If every delivery to an endpoint fails for **3 consecutive days**, the endpoint is disabled automatically and the Owner is emailed.

**Verifying requests**
Each request includes an `X-Larkspur-Signature` header: an HMAC-SHA256 of the raw request body, using the endpoint's signing secret. The secret is shown once when you create the endpoint and can be rotated. Compare the header with your own computed value before trusting the payload.

**Downgrades**
If the account moves below Pro, webhooks are paused (KB-027).
