# Embedding forms on your website

Embedding is available on **all plans**, including Free. Open the form and go to **Share > Embed** to choose a style:

- **Inline (JavaScript):** places the form inside your page and resizes its height automatically. Recommended.
- **Popup:** opens the form in an overlay when a visitor clicks a button you choose.
- **Full page:** the form fills the whole page.
- **Plain iframe:** for website builders that don't allow scripts. Iframes have a fixed height, so set the height value tall enough that the whole form, including the submit button, is visible.

Copy the code and paste it into an HTML or embed block in your website builder.

**Prefilling and tracking with hidden fields**
Add hidden fields to your form and pass values in the form URL or embed code, for example `?source=spring-landing-page`. Hidden field values are saved with each response, so you can record which page or campaign a response came from.

**Branding**
On Free, embedded forms show the "Made with Larkspur" badge. It is removed on Starter and above (KB-039).

**Custom domains**
Forms on a custom domain (Pro and above, KB-036) can be embedded the same way.

If the embed shows a blank space or doesn't appear, see KB-022.
