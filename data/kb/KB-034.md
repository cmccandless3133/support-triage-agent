# Conditional logic

Conditional logic is available on **Starter and above**. It lets a form change based on answers.

**What logic can do**
- Show or hide a field.
- Skip to a specific page.
- Send respondents to a specific end screen.

**Rule limits**
- Starter: up to **25 logic rules** per form.
- Pro and Business: unlimited rules.

**Adding a rule**
1. Select the field the rule depends on (for example, "Will you attend?").
2. Click **Logic > Add rule**.
3. Set the condition (for example, *is* "Yes") and the action (for example, *show* "Number of guests"). Fields targeted by a *show* action are hidden until the condition is met.
4. Click **Preview** to test before publishing.

**How rules are evaluated**
Rules run from top to bottom. If two rules affect the same field, the last matching rule wins, so conflicting show and hide rules can override each other. Hidden fields are not submitted and appear empty in results.

**Free plan**
Logic rules cannot be created on Free. If the account moves to Free, existing rules are disabled and the form shows every field; the rules return when you upgrade.

**Hitting the Starter limit**
Combine conditions in a single rule using *all*/*any* matching, or upgrade to Pro for unlimited rules.
