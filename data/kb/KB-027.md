# Integrations overview and plan availability

**Native integrations by plan**
- Google Sheets: all plans, including Free
- Slack, Zapier and Mailchimp: Starter and above
- Stripe payments and webhooks: Pro and above

Integrations are connected per form from Form > Integrations.

**REST API**
The REST API is available on Pro and Business. Create API keys in Settings > Developer. Rate limits are **60 requests per minute** on Pro and **300 requests per minute** on Business. Requests over the limit receive HTTP 429.

**Downgrades**
If you move to a plan that doesn't include an integration, the integration is **paused, not deleted**, and resumes when you upgrade again. Responses received while it was paused are not sent retroactively, except to Google Sheets, which has a Resync option (KB-030).

**Activity log**
Every integration has an activity log under Form > Integrations > Activity showing successes and errors for the last **14 days**. Check it first when an integration stops working.

**Other tools**
Larkspur does not build custom integrations for individual customers. For tools without a native integration, use Zapier (KB-028) or webhooks (KB-033). Support can troubleshoot the Larkspur side of a connection but cannot configure or debug settings inside third-party accounts.
